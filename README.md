\### Note on the SCADA HMI

&#x20;  SCADA\_HMI.py targets the V2 canonical telemetry format. The V6 parallel

&#x20;  firmware emits a compact 20 ms REPORT stream parsed by the analysis scripts

&#x20;  (e.g. analyse\_v6\_repeatability.py), not by the live HMI. Updating the HMI to

&#x20;  the V6 stream is tracked as future work.
